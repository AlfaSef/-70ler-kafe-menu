# 70ler Kafe Menü

Bu proje Supabase tabanlı mobil menü ve yönetici panelidir.

Kurulum:
1. config.js dosyasında BURAYA_SUPABASE_API_URL yerine Supabase API URL değerini yazın.
2. BURAYA_PUBLISHABLE_KEY yerine Supabase Publishable key değerini yazın.
3. index.html ve config.js dosyalarını GitHub repository köküne yükleyin.
4. Cloudflare Pages ile GitHub repository'yi bağlayın.

Not: Secret/service_role key kullanılmaz.
